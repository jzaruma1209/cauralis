# Animaciones

Guarda aquí las animaciones que hagas en HTML (con su CSS/JS) para usarlas después en el sitio.

- Esta carpeta NO se publica en cauralis.com: es solo para guardar y probar.
- Una animación por carpeta, por ejemplo:

```
animaciones/
  titulo-revelado/
    index.html
    estilos.css
    script.js
  boton-brillo/
    index.html
```

- Para verla, abre su `index.html` con doble clic en el navegador.
- Cuando quieras usar una en la página, pide que la conviertan en un componente dentro de `components/animations/`.
